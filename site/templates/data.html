Use the data

Everything on the site is published as files. They are rebuilt after every collection; there is no API key and no rate limit.

FileContents
data/latest.jsonEverything the site shows: fixings, latest offers in EUR, providers and their classification, collection health.
data/fixings.csvEvery fixing ever published, one row per index per day.
data/fixings.jsonlThe hash-chained fixings ledger, as stored.
data/offers-latest.csvLatest price of every offer, native currency and EUR per GPU-hour.
ledger/ (repository)Full history: every price ever observed, every run, verbatim source snapshots.

Prices are list prices excluding VAT. EUR values use the ECB reference rate of the observation day.

Cite

CompEU, methodology {{ data.methodology.id }}, fixing of <date>. Lugano, Switzerland. Licensed under CC BY 4.0.

Verify

git clone {{ data.repo }}
cd compeu
uv run compeu verify

The check recomputes every hash in the ledger and fails if any past price, run or fixing was changed.
